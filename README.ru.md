# TailyaGTK

**Стеклянная (glassmorphism) тема для GNOME — Shell, GTK 3, GTK 4 и libadwaita.**

Тот же полупрозрачный фиолетовый вид, что и у [Tailya](https://github.com/kila2121/Tailya.git), теперь распространённый на все приложения на рабочем столе.

Всплывающие меню, панель быстрых настроек и календарь получают полупрозрачную тёмную поверхность с мягкой тенью. Дни календаря становятся круглыми пилюлями. У уведомлений появляются аккуратные скругления 16 px. Приглушённый фиолетовый акцент, которым отмечается включённый тумблер в оболочке, — это тот же фиолетовый, что вы видите в Firefox, GIMP, «Файлах» и «Настройках», потому что TailyaGTK оформляет все три системы тем из одной палитры.

> **TailyaGTK покрывает три независимые системы** — GNOME Shell, GTK 3 и GTK 4 с libadwaita. Каждая применяется своим механизмом. `./install.sh --apply` настраивает все три одной командой; если ставите вручную, внимательно прочитайте разделы ниже.

## Что меняется

**GNOME Shell** — меню верхней панели, быстрые настройки, календарь, уведомления, док:

- **Стеклянные поверхности** — всплывающие меню, быстрые настройки и календарь используют полупрозрачный тёмный фон с мягкой тенью.
- **Док и обзор** — кнопки дока и плитки обзора теряют рамки; сам док сохраняет лёгкую стеклянную подложку.
- **Календарь** — дни под курсором и текущий день становятся круглыми пилюлями; подписи и стрелки навигации получают единый читаемый стиль.
- **Уведомления** — скругления 16 px, мягкая тень и аккуратно подобранная прозрачность текста.
- **Фиолетовый акцент** — включённые тумблеры, ползунки и переключатели используют один приглушённый фиолетовый (`rgb(117, 84, 209)`).
- **Плавные переходы** — 150 мс на наведение, фокус и нажатие.

**Приложения на GTK 3 и обычном GTK 4** — Firefox, GIMP, старые приложения, обычные GTK 4:

- **Пилюлеобразные контролы** — кнопки, поля ввода, счётчики и группы связанных кнопок получают крупный радиус скругления.
- **Матовые заголовки окон** — заголовки теряют градиент и становятся плоской, чуть более тёмной поверхностью.
- **Фиолетовый акцент везде** — suggested-кнопки, рамки фокуса, выделения, ползунки и прогресс-бары используют тот же фиолетовый, что и оболочка.
- **Скруглённые меню и попапы** — 14–16 px на меню, тултипах и попапах.

**Приложения на libadwaita** — «Файлы», «Настройки», «Текстовый редактор», «Консоль»:

- **Перекрашенный акцент** — каждый `@define-color`, который предоставляет Adwaita (`accent_bg_color`, `accent_color`, `accent_fg_color` и их hover/active-состояния), установлен в палитру TailyaGTK.
- **Перекрашенные сайдбары, карточки, диалоги и попапы** — тона фона подогнаны под поверхности GTK 3 и оболочки, чтобы весь рабочий стол читался как одна тема.

Тема — чистый CSS. Никаких расширений кроме User Themes, никаких скриптов во время работы. Установщик только копирует файлы и создаёт один симлинк.

## Что в комплекте

| Папка | Что оформляет |
| --- | --- |
| `gnome-shell/` | меню верхней панели, быстрые настройки, календарь, уведомления, диалоги, док |
| `gtk-4.0/libadwaita.css` | приложения на libadwaita («Файлы», «Настройки», «Текстовый редактор», …) |
| `gtk-4.0/gtk.css` | обычные GTK 4-приложения без libadwaita |
| `gtk-3.0/` | GTK 3-приложения (Firefox, GIMP, старые приложения) |
| `src/` | SCSS-исходники, из которых генерируются GTK-стили |
| `tools/recolor.py` | перекрашивает стоковый CSS Adwaita в палитру TailyaGTK |
| `build.sh` | собирает `gtk-3.0/gtk.css` и `gtk-4.0/gtk.css` |
| `install.sh` / `uninstall.sh` | устанавливает тему и линкует `libadwaita.css` |

## Требования

| Требование | Детали |
| --- | --- |
| GNOME Shell | 45 или новее (проверено на 48) |
| GTK | 3.24 или новее, 4.14 или новее |
| User Themes | [расширение](https://extensions.gnome.org/extension/19/user-themes/), включено — нужно для части Shell |
| GNOME Tweaks | опционально, но это самый простой способ выбрать тему Shell |

## Установка

**1. Склонируйте или скопируйте тему.**

Из архива:

```bash
mkdir -p ~/.themes
tar -xf tailya-gtk.tar.gz -C ~/.themes
```

Из папки проекта:

```bash
mkdir -p ~/.themes
cp -r /path/to/TailyaGTK ~/.themes/
```

Для всех пользователей:

```bash
sudo tar -xf tailya-gtk.tar.gz -C /usr/share/themes
```

Замените `tailya-gtk.tar.gz` и `/path/to/TailyaGTK` на реальные имена. GNOME также читает темы из `~/.local/share/themes/`, так что подойдёт любая из двух домашних локаций.

**2. Запустите установщик.**

```bash
cd ~/.themes/TailyaGTK
./install.sh --apply
```

Скрипт скопирует тему в `~/.themes/TailyaGTK`, слинкует `libadwaita.css` с `~/.config/gtk-4.0/gtk.css` и выберет тему и тёмную схему через `gsettings`. Если хотите сделать это вручную, вот три шага, которые выполняет скрипт:

```bash
ln -sf ~/.themes/TailyaGTK/gtk-4.0/libadwaita.css ~/.config/gtk-4.0/gtk.css
gsettings set org.gnome.desktop.interface gtk-theme 'TailyaGTK'
gsettings set org.gnome.desktop.interface color-scheme 'prefer-dark'
```

Если установлен `flatpak`, установщик также даёт Flatpak-приложениям доступ на чтение к `~/.themes` и `~/.config/gtk-4.0`.

**3. Выберите тему Shell.**

Установите и включите расширение **User Themes**, затем откройте **GNOME Tweaks → Внешний вид** и выберите **TailyaGTK** в разделе **Shell**. Если GNOME Tweaks не установлен, поставьте его из репозиториев дистрибутива.

**4. Выйдите и войдите обратно.**

libadwaita читает `~/.config/gtk-4.0/gtk.css` при запуске приложения — полный выход и вход гарантирует, что все работающие приложения подхватят новые цвета. На X11 можно также нажать `Alt+F2`, ввести `r`, нажать `Enter` — это перезагрузит только Shell.

## Почему два файла GTK 4

Обычные GTK 4-приложения читают активную тему GTK из `~/.themes/TailyaGTK/gtk-4.0/gtk.css`. Приложения на libadwaita этого не делают: они игнорируют выбранную тему GTK и читают только `~/.config/gtk-4.0/gtk.css`. Установщик создаёт там симлинк. Поэтому в теме два GTK 4-файла: полный для обычного GTK 4 и короткий, который только переопределяет цветовую палитру для libadwaita.

## Кастомизация

**Стили Shell** лежат в [`gnome-shell/gnome-shell.css`](gnome-shell/gnome-shell.css). Фиолетовый акцент встречается в трёх оттенках — замените все три, чтобы он остался единообразным:

```css
rgb(117, 84, 209)  /* обычный   */
rgb(135, 105, 222) /* наведение */
rgb(100, 70, 190)  /* нажатие   */
```

**Прозрачность панели.** Стеклянные поверхности используют `rgba(30, 30, 30, 0.5)`. Уменьшите альфу для большей прозрачности, увеличьте — для более плотной панели.

После правки CSS Shell перезагрузите через `Alt+F2` → `r` на X11 или выйдите и войдите снова на Wayland.

**Стили GTK** генерируются из одной палитры. Чтобы перекрасить всю тему — кроме Shell — отредактируйте один файл и пересоберите:

```bash
nano src/_palette.scss      # меняйте $accent, $window-bg, $radius-s, и т.д.
./build.sh
./install.sh --apply
```

> **Один подводный камень:** исходный акцент Adwaita (`#15539e`) и целевой акцент (`#7554d1`) жёстко прописаны и в `tools/recolor.py` как `ACCENT_SRC` и `ACCENT_DST`. Если меняете `$accent` в `_palette.scss`, обновите и `ACCENT_DST` в `recolor.py` — иначе базовый CSS перекрасится в старый акцент, а override'ы наложатся сверху новым, получится двухцветный результат.

## Сборка из исходников

Стили GTK 3 и обычного GTK 4 *генерируются*, а не пишутся руками. Пайплайн берёт стоковый CSS Adwaita, уже вкомпилированный в `libgtk-3.so` и `libgtk-4.so`, перекрашивает его и дописывает override'ы из `src/`. Стиль Shell написан вручную и в сборке не участвует.

Для каждого из GTK 3 и GTK 4 `build.sh` делает четыре шага:

**1. Извлекает стоковый CSS Adwaita из установленной библиотеки GTK.**

```bash
gresource extract "$GTK3_LIB" /org/gtk/libgtk/theme/Adwaita/gtk-contained-dark.css > build/gtk3-base.css
```

Это даёт полный CSS Adwaita — тысячи строк, стилизующих каждый виджет, который знает GTK.

**2. Перекрашивает его в палитру TailyaGTK.**

```bash
python3 tools/recolor.py build/gtk3-base.css build/gtk3-base.recolored.css "resource:///org/gtk/libgtk/theme/Adwaita/assets/"
```

`recolor.py` проходит по CSS, заменяет синий акцент Adwaita (`#15539e`) фиолетовым TailyaGTK (`#7554d1`), перекрашивает серые тона по градиенту и переписывает `url("assets/…")`, чтобы картинки грузились из ресурсов GTK, а не из несуществующей папки.

**3. Компилирует SCSS-override'ы.**

```bash
sassc -t expanded -I src src/gtk3.scss build/gtk3-overrides.css
```

`src/gtk3.scss` и `src/gtk4.scss` импортируют палитру и shape-партиалы, эмитят `@define-color` и компилируются в обычный CSS.

**4. Склеивает базу и override'ы.**

```bash
cat build/gtk3-base.recolored.css build/gtk3-overrides.css > gtk-3.0/gtk.css
```

Порядок важен: база первая, override'ы вторые. При равной специфичности селекторов выигрывает более позднее правило — именно так пилюлеобразные кнопки из `src/_gtk3-shape.scss` перебивают квадратные от Adwaita.

GTK 4 проходит те же четыре шага с `src/gtk4.scss` плюс один дополнительный: скомпилированные override'ы также копируются в `gtk-4.0/libadwaita.css`, чтобы установщик мог слинковать их с `~/.config/gtk-4.0/gtk.css`.

### Зависимости

```bash
sudo apt install sassc libglib2.0-bin libgtk-3-0 libgtk-4-1
```

- `sassc` — компилятор SCSS
- `libglib2.0-bin` — предоставляет `gresource`
- `libgtk-3-0`, `libgtk-4-1` — библиотеки, из которых `build.sh` извлекает Adwaita

Для тестов:

```bash
sudo apt install xvfb imagemagick python3-gi libadwaita-1-0 gir1.2-adw-1
```

### Тестирование

```bash
./tests/run_tests.sh
```

Набор выполняет три проверки:

- **Парсинг CSS** — `lint_gtk3.py` и `lint_gtk4.py` загружают сгенерированные стили через настоящие GTK-парсеры и сообщают о любых синтаксических ошибках. Быстрый способ поймать опечатку в партиале до установки.
- **Скриншоты** — `preview_gtk3.py` и `preview_gtk4.py` открывают окна с типичными виджетами (кнопки, поля ввода, переключатели, меню, списки), рендерят их под `xvfb` и сохраняют PNG в `/tmp/tailya-test/` для визуального сравнения.
- **Покрытие libadwaita** — `preview_gtk4.py` задействует `Adw.ApplicationWindow`, `Adw.HeaderBar`, `Adw.ToolbarView` и `Adw.ActionRow` — виджеты, чьи цвета берутся из `@define-color` в `src/gtk4.scss`.

### Файлы, которые не надо редактировать

Это сгенерированные файлы. Любое изменение будет перезаписано при следующем `./build.sh`:

- `gtk-3.0/gtk.css`, `gtk-3.0/gtk-dark.css`
- `gtk-4.0/gtk.css`, `gtk-4.0/gtk-dark.css`, `gtk-4.0/libadwaita.css`
- всё в `build/`

Чтобы изменить внешний вид виджета, правьте `src/_gtk3-shape.scss` или `src/_gtk4-shape.scss`. Чтобы изменить Shell, правьте `gnome-shell/gnome-shell.css` — он написан вручную и в сборке не участвует.

## Совместимость

| Стек | Статус |
| --- | --- |
| GTK 3.24.41 | ✅ Проверено (скриншоты) |
| GTK 4.14 + libadwaita 1.5 | ✅ Проверено (скриншоты) |
| libadwaita 1.6 / 1.7 (GNOME 47 / 48) | ⚠️ Селекторы и механизм цветов сверены с исходниками libadwaita 1.7 |
| GNOME Shell 48 | ✅ Повседневная работа (Debian 13) |
| GNOME Shell 43–47 | ⚠️ Ожидается работа, не проверено |
| GNOME Shell 49+ | ❌ Не проверено |

Только тёмная — светлого варианта нет. Неизвестные селекторы GTK и Shell игнорируют, поэтому на другой версии в худшем случае покажется стоковый стиль.

## Решение проблем

**Тема Shell не появляется в списке.**
Убедитесь, что путь ровно `~/.themes/TailyaGTK/gnome-shell/gnome-shell.css`, перезапустите GNOME Tweaks и проверьте, что User Themes включён.

**Тема Shell выбрана, но ничего не меняется.**
На Wayland темы Shell применяются при входе — выйдите и войдите снова. На X11 перезагрузите через `Alt+F2` → `r`.

**Приложения GTK выглядят стоково.**
Проверьте, что `gsettings get org.gnome.desktop.interface gtk-theme` возвращает `'TailyaGTK'`. Затем полностью закройте и откройте приложение — темы GTK читаются при старте.

**Приложения libadwaita («Файлы», «Настройки», «Текстовый редактор») выглядят стоково.**
Проверьте, что `~/.config/gtk-4.0/gtk.css` — симлинк на `~/.themes/TailyaGTK/gtk-4.0/libadwaita.css`. Затем полностью закройте и откройте приложение.

**Некоторые элементы выглядят неоформленными.**
GNOME 47+ мог переименовать или добавить селекторы. Укажите вашу версию GNOME и приложите скриншот — или поправьте CSS сами.

**Экран входа всё ещё стоковый.**
Так и должно быть: GDM использует свою тему и не грузит темы из `~/.themes`.

## Удаление

```bash
./uninstall.sh
```

Скрипт удалит `~/.themes/TailyaGTK`, восстановит предыдущий `~/.config/gtk-4.0/gtk.css` из `gtk.css.glassy-backup` и отзовёт Flatpak-override'ы. Затем переключите тему обратно в GNOME Tweaks.
